# Create: Display Regex 玩家指南

这是 Create Fly 的 Display Link 附加模组。它会在文字发送到显示目标前进行正则替换；只改变显示内容，
不会修改包裹地址、库存或来源方块的数据。

![正则配置界面](docs/images/regex-configuration-zh-cn.png)

## 安装

将 Release 页面下载的 `create-display-regex-*.jar` 放入与下列版本兼容的 Fabric 实例 `mods` 文件夹：

| 依赖 | 版本 |
| --- | --- |
| Minecraft | `26.2-rc-2` |
| Fabric Loader | `0.19.3+` |
| Fabric API | `0.152.0+26.2` |
| Create Fly | `6.0.9-1` |

服务器必须安装本模组。想在游戏中配置正则规则的客户端也需要安装。

## 怎么使用

1. 正常放置并配置 Create Fly 的 Display Link。
2. 点击确认按钮左边的“小配置”图标，打开“显示链接器正则处理”。
3. 打开“启用正则处理”。
4. 在“匹配正则”填写要寻找的文字规则。
5. 在“替换为”填写新文字；留空表示删除匹配到的内容。
6. 点击绿色确认按钮，再关闭 Display Link 界面保存。

## 常用例子

| 目标 | 原文本 | 匹配正则 | 替换为 | 显示结果 |
| --- | --- | --- | --- | --- |
| 删除第一个路径段 | `AAA/BBB/CCC` | `^[^/]+/` | 留空 | `BBB/CCC` |
| 只保留最后一段 | `AAA/BBB/CCC` | `^.*/` | 留空 | `CCC` |
| 把斜杠换成横线 | `AAA/BBB/CCC` | `/` | ` - ` | `AAA - BBB - CCC` |
| 删除所有数字 | `item-42-box` | `\d+` | 留空 | `item--box` |

本模组使用 Java 的 `Matcher.replaceAll` 规则：一条规则会替换所有匹配位置。替换内容中可用 `$1`、`$2`
引用圆括号捕获的分组。

## 不会写正则？

从基础的字符、`*`、`+`、`?`、`[]`、`^` 和 `$` 开始即可。可在
[菜鸟教程：正则表达式语法](https://www.runoob.com/regexp/regexp-syntax.html) 学习和查阅这些语法。

该网站适合学习基础语法；本模组实际使用 Java 正则。复杂的 Java 专有写法或替换分组请先在简单文本上测试。

## 出错时

- 红色“正则无效”表示 Pattern 或替换内容不合法；修正后才能应用。
- 无效规则不会让游戏崩溃，显示会保持原文本。
- 正则只作用于显示文本，不能用来更改物流、包裹地址或库存数据。
